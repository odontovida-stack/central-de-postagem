Política de Privacidade · Central de Postagem

A Central de Postagem é a ferramenta interna que publica os vídeos e posts dos canais e páginas de Luiz Alexandre Molina Soares (The American File, Before History Changed, Brazil on a Budget, Brasil 23:59 e páginas LLShop).

Dados de usuários do Google/YouTube: a ferramenta usa a API do YouTube só para enviar e agendar vídeos nos canais do próprio dono. Ela não coleta, não vende e não compartilha dados de outras pessoas. O token de acesso fica guardado como segredo criptografado no GitHub e é usado apenas para o envio dos vídeos.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Para revogar o acesso: myaccount.google.com/permissions.
